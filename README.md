# Chung Tay Vì Miền Trung – Web tĩnh (HTML/CSS/JS + Tailwind CDN)

## Cấu trúc
```
flood_relief_site/
├─ index.html
├─ css/
│  └─ styles.css
└─ js/
   └─ app.js
```

## Cách chạy
1. Mở `index.html` bằng trình duyệt (double-click).
2. Không cần máy chủ hay cài đặt gì thêm (Tailwind dùng CDN).

## Tùy chỉnh nhanh
- Màu chủ đạo: đổi `bg-rose-600`/`hover:bg-rose-700` trong `index.html`.
- Ảnh: thay URL ảnh Unsplash trong phần Gallery.
- Thông tin chuyển khoản: chỉnh trong phần “Về chiến dịch” & trong Modal.
- Nếu muốn **web tĩnh hoàn toàn** (không alert), xóa các `alert(...)` trong `js/app.js`.
